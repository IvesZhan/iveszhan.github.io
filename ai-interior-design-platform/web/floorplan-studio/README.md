# 金地大成乐府 · 奶油风样板

案例库入口是 [方案预览](./index.html)。在仓库根目录运行 `python3 -m http.server 8766 --bind 127.0.0.1 --directory apps/web`，然后访问 `http://127.0.0.1:8766/floorplan-studio/`。编辑器的家具、材质和布局修改保存在当前浏览器，也可以通过编辑器导出 JSON 备份。

- [户型数据](./jindi-cream.json) 以米记录房间、墙、门窗与家具。以 12100 × 13300 毫米的装修布置截图建立空间关系，原始勘测图用于对照门窗及结构线索。层高 2.8 米为预览假设。实际洞口、完成面和承重属性需现场复核。
- [编辑器](./editor/index.html) 使用 [floorplan-3d 提交 `730ec09`](https://github.com/wy51ai/floorplan-3d/tree/730ec0923a018fdf38b4687c5ef385c7dcac451f) 的 2D、3D 编辑和漫游代码，适配该户型并使用本地 Three.js r160。保留 [上游 MIT 许可证](./editor/LICENSE.floorplan-3d.txt)。
- [客餐厅效果意向](./living-dining-cream.webp) 由内置 ImageGen 参考布置图生成，用于讨论主材、软装和光线。平面定位、净距和门窗以模型及现场复核为准。
